# 周術期の薬剤管理ナビ

2026-09-29実装。配信ファイルはリポジトリ直下の `periop_medication_navigator.html`。
成人・非心臓手術を対象に、38の薬剤／分類エントリー、22の管理ルールを収載する。
数値スコアで疾患を順位付けするツールではないため、条件分岐を純粋関数 `PeriopEngine.evaluate` として実装した。

## 実装範囲

- 術前準備、休薬忘れ・誤休薬、術後再開の3場面。
- 一般名・商品名・分類、ひらがな／半角カナ／用量を含む検索。
- 複数薬を登録。スージャヌ・トラディアンス・エクメットは成分別に展開。
- 固定日付を支持するルールだけで休薬開始目安を表示。暦日と24時間を区別し、日本時間で処理。
- 最終投与不明、日時矛盾、必要条件不足、適用範囲外、緊急手術、根拠期限切れを別々に処理。
- 休薬開始と最終服用の予定は別物。用量・投与頻度は記録用で、投与量や最終服用時刻を自動算出しない。
- 投与中断が問題になる薬の代替経路確認。術後の再開指示は担当医が行う。
- 未収載薬も明示的に一覧へ追加できる。自動的な継続扱いにはしない。
- 根拠・該当箇所・未確定事項・入力条件を含む申し送り、印刷。
- 外部API・外部フォント・外部JSなし。患者識別情報の入力欄・永続保存・入力の送信なし。
- 既存の抗血栓薬ツールへリンク。患者情報は自動転送しない。

## 編集・ビルド

`evidence.json` は薬剤カタログ・文章・出典の機械可読台帳。
`app.js` は判定と画面操作、`page.html` は画面テンプレート。
配信HTMLを直接編集せず、元ファイルを編集後にビルドする。

```powershell
$env:PYTHONIOENCODING='utf-8'
python assets/periop-medication/build.py
node assets/periop-medication/test.js
python check_sw_cache.py
```

ブラウザ検査は別のターミナルで `python -m http.server 8769 --bind 127.0.0.1` を開始し、
`python assets/periop-medication/qa_browser.py` を実行する。
検査画像・印刷PDFは一時フォルダ `periop-medication-20260929/qa/` に保存する。

## 医学的な確認範囲・限界

公式の学会・規制当局・製造販売元・専門職団体の資料を対象とした確認であり、系統的レビューではない。
PubMed検索の式・件数・query translationは `pubmed-search.json` に保存した。
検索時にPubMedが解釈しなかった句は同ファイルの警告として保持し、網羅性の根拠にはしない。
AHA文献はDOIから `pubmed_verify.py` で著者・年・誌名を照合し exit 0。
実装に用いた記載は学会公式スライドで本文確認した。出力は `aha-metadata-verification.txt`。
ADA 2026は書誌確認済みだが、`pubmed_fulltext.py` が抄録のみ取得の exit 2となり不採用。
直接ダウンロードが403になるUKCPA資料はwebツールで本文を確認した。403を本文確認成功とは扱っていない。

### 元記事から、そのまま転記しなかった事項

| 項目 | 実装 |

| メトホルミンの一律48時間前／術後48時間 | 国内電子添文2.3の禁忌と、学会の小手術の説明を区別。48時間は電子添文8.1(4)の造影後条件として扱う。 |
| ACE/ARBの一律休薬 | HFrEFと高血圧を区別。高血圧・血圧管理良好・高リスク手術でのみ24時間前省略を候補として示す。 |
| β遮断薬の一律継続 | AHAの既存治療継続と、メインテートの国内電子添文8.3の投与回避記載を併記。担当科の管理指示を確認する。 |
| SERM全例4週間 | ラロキシフェンは長期不動開始3日前を起点にする。他のSERMへ自動外挿しない。 |
| 経口避妊薬と経皮HRTの統一 | ヤーズの禁忌は製品固有のルール。他の製品・剤形は国内添文確認へ。 |
| MAO-B阻害薬全例2～3週間 | 併用薬と国内製品の禁忌・相互作用を確認。英国の継続方針を国内標準と断定しない。 |
| 食事開始で全薬再開 | 薬剤別の条件を表示。インスリン等は食事開始を待たず投与計画を確認。 |

薬効分類で登録する項目は、代表薬資料を示す「確認経路」であり全製品の添文照合済み一覧ではない。
腫瘍・免疫抑制薬、未収載の骨粗鬆症薬、漢方・サプリメントは薬剤別確認へ進む。
インスリン単位・ステロイド補充量・術中処置の用量計算、手術の実施許可、処方指示は行わない。
外部の臨床専門家による独立レビューは未記録。2026-09-29、ユーザーから「公開してください」と明示承認を受領。ブログ改変は今回の公開作業に含めない。

## 検証

2026-09-29：68の判定・日付・検索・入力症例テストを通過。
実ブラウザで1280×720、390×844、38項目全追加、配合剤、3場面、入力変更時の結果消去、
対象外・緊急経路、入力文字列のHTML無害化、単一ファイルのオフライン動作を検査。
HTTP・file両方でJavaScriptエラーなし。印刷をPDF化し、入力条件・本文・出典の全ページを目視確認。

SWはv182→v183、一覧カードと新HTMLを追加。
`check_sw_cache.py` で既存の追跡済み `infographics/vitamin-b12-deficiency/index.html` の登録漏れが検出されたため、
同時にASSETSへ登録して整合を回復。B12の本文は変更していない。
ローカル確認版の納品後、2026-09-29の明示承認に基づき公開する。

## 保守

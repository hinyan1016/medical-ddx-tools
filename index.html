診療ツール

🧠
蘇生後の脳機能予後判定支援
成人の心停止蘇生後に、評価時期・交絡因子・神経所見・脳波・SSEP・NSE・画像を整理。所見の食い違いや未確認項目を表示し、記録のコピー・印刷に対応します。
ERC/ESICM 2025・AHA 2025 / 医療従事者向け
📋
日常生活自立度 判定支援ツール
障害高齢者・認知症高齢者の日常生活自立度を公的基準に沿って別々に確認。回答に対応する参考区分と確認事項を表示し、記録のコピー・印刷に対応します。
2種類の自立度 / 未確認時は保留 / 要介護度は判定しません
💊
周術期の薬剤管理ナビ
糖尿病薬・循環器薬・神経疾患の薬などの休薬・継続・再開を条件別に確認。複数薬の一覧、休薬忘れ時の確認、申し送り・印刷に対応。
医療従事者向け / 根拠・未確認条件を表示
🩸
周術期抗血栓薬コンサルト返書ツール
脳梗塞既往患者の周術期抗血栓療法について、消化器内視鏡・外科手術・抜歯・白内障・皮膚小手術の各ガイドラインから休薬・継続の参考情報と返書文案を作成します。機械弁・発症3か月以内・ステント留置後など定型判断の範囲外は休薬日数を出さず個別協議を促します。医療従事者向け。
⚡
抗てんかん薬 AED Load・等価換算ツール
WHO-DDD（Defined Daily Dose）とILAE基準に基づき、服用中の抗てんかん薬の1日総負荷量（AED Load）、 カルバマゼピン換算比、有効血中濃度（TDM基準値）、相互作用アラートを即時計算・評価します。
WHO-DDD準拠 / 14薬剤 / TDM基準値
💊
抗てんかん発作薬 相互作用チェッカー
服用中の抗てんかん発作薬と併用薬を選ぶと、濃度が動く組み合わせと対応を、出典つきで表示する医療者向けツール。国内電子添文とPubMedで実在を確認した文献に基づきます。
19剤 × 併用薬76種 / 国内の併用禁忌 / 出典つき
🧠
MNI脳血管支配領域 3Dアトラス
急性期脳梗塞1,298例のDWI病変から作られたMNI標準脳の血管支配領域アトラス（Liu et al. Sci Data 2023）。3断面と3D表示、30領域／4大血管の切り替え、各領域の閉塞症候と参考文献、症候からの逆引き、病変を描いて領域の内訳を計算する機能、クイズ。
3断面＋3D / 30血管領域 / 病変の領域内訳
🧠
BFCRS 緊張病評価尺度 計算ツール
Bush-Francis Catatonia Rating Scale（23項目）。スクリーニング14項目で2項目以上陽性→カタトニア疑い、総得点で重症度を評価します。
23項目 / スクリーニング14項目
🫘
急性腎障害（AKI）鑑別診断ツール
緊急度評価、尿路閉塞除外、循環動態評価、腎毒性物質確認、尿検査所見、臨床所見・病歴から 腎前性・腎性（ATN/AIN/RPGN/TMA）・腎後性の13疾患を系統的に鑑別します。
6ステップ / 13疾患
🫧

🦵

12ステップ / EAN 2024準拠
⚡

7ステップ / 分岐型アルゴリズム
🔥

7ステップ / 14疾患鑑別
🩺

7ステップ / 9病態鑑別 + 単位換算

頭痛鑑別診断ツール
発症様式・Red Flags（SNNOOP10）・持続時間・性状・随伴症状・眼症状・増悪因子の7ステップで、 危険な二次性頭痛を先に拾い、一次性頭痛を積極的に診断します。ICHD-3・NICE CG150・ACR 2023準拠。
7ステップ / 22疾患鑑別
📋
HIT-6 頭痛インパクトテスト 採点ツール
公式質問票に記入された6項目の回答を転記すると、合計点（36〜78点）と4段階の支障度（≦49／50〜55／56〜59／≧60）を判定。前回値を入れると変化量を、慢性片頭痛で推奨される「6点以上の低下」などの目安と照らして表示します。記録用サマリのコピーまで一画面で。
6項目 / 36-78点 / 4段階判定 + 変化量
🗓️
MIBS-4 片頭痛発作間欠期負担スケール 採点ツール
過去4週間の「頭痛のない日」の負担を測る4項目の回答を転記すると、合計点（0〜12点）となし／軽度／中等度／重度の区分、原著（Buse 2009）の対応目安（非薬物療法・急性期治療の最適化・予防薬の検討／提案）を表示。0〜16点版との違いの注意つき。
4項目 / 0-12点 / 発作間欠期の負担
📆
MIDAS 片頭痛支障度評価 採点ツール
過去3か月に頭痛で仕事・学校・家事・余暇ができなかった日数（5問）を転記すると、合計点と Grade I〜IV（0〜5／6〜10／11〜20／21以上）を判定。治療前の値と比べて、米国頭痛学会 2021 の改善基準（治療前11〜20は5点以上、20超は30%以上の低下）を満たすかを表示します。頭痛日数・痛みの強さ（採点外）も記録できます。
5問 / 日数合計 / Grade I-IV + AHS改善基準
🌀
めまい鑑別診断ツール
症候群分類（AVS/t-EVS/s-EVS/慢性）を入口に、危険徴候・眼振所見・聴覚症状・片頭痛関連・慢性特徴・背景因子の7ステップで、 後方循環脳卒中を見逃さず、前庭神経炎・BPPV・前庭性片頭痛・メニエール病・PPPDなど13疾患を系統的に鑑別します。
7ステップ / 13疾患鑑別
🚨

8ステップ / 20疾患鑑別
🧠

分岐型フローチャート / ACNS 2021準拠
💤
てんかん重積 麻酔薬導入 判断整理ツール

5ステップ / 一次文献ベース・医療者向け
🌡️

💔

🧠

GLIM基準 低栄養診断ツール
表現型基準3項目（意図しない体重減少・低BMI・筋肉量減少）と病因基準2項目（食事摂取量減少/消化吸収・疾患負荷/炎症）を入力すると、「表現型1つ以上＋病因1つ以上」で低栄養の有無を判定。BMIは身長体重から自動計算（年齢70歳で区切り）。重症度（中等度/重度）は体重減少で判定し、日本人カットオフ未確定のBMI研究値は参考表示。記録用サマリのコピーまで一画面で（JSPEN 2024 / 2025 5年アップデート対応）。

リフィーディング症候群 リスク判定ツール

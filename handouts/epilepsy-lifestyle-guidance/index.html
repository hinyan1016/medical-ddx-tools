生活の 6つのポイント

生活の工夫は、薬の「代わり」ではなく「上乗せ」です。 発作の引き金（誘因）を減らし、起きたときに安全に対応できれば、いつもの生活を続けられます。大切なのは「がまん」より「無理なく続けること」。今日できる一つから始めましょう。

動画・くわしい解説はこちら

1薬をきちんと続ける

  • 抗てんかん薬は、自己判断でやめたり減らしたりしない
    → 飲み忘れ・急な中断は、発作の最も多い引き金です
  • 飲み忘れを防ぐ工夫を（お薬カレンダー・アラーム・予備を携帯）
  • 飲みにくさ・副作用がつらいときは、やめる前に相談を

2眠りを整える

  • 睡眠不足を避ける。決まった時間に寝起きする
    → 寝不足は多くの人で発作が出やすくなります。徹夜は避けて
  • 大人は6〜8時間を目安に、規則正しい生活リズムを

3引き金（誘因）を避ける

  • お酒は控えめに。過労・強いストレスをためこまない
    → 感じ方には個人差。自分の引き金は発作日誌で見つけましょう
  • 点滅する光やゲームで調子が悪くなる人は、距離・休憩を

4安全に暮らす

  • 入浴は原則シャワー。湯船は見守り・浅め・短時間で
    → 発作が続く間は、家族にそばにいてもらいましょう
  • 運転は主治医と確認。水辺・高所・機械の作業は配慮を

5発作が起きたときの対応

  • あわてず時間を計る。周りの危険を片づけ、横向きに
    → 口に物を入れない・押さえつけない。様子を記録・撮影を
  • 頓用のお薬（座薬・口や鼻の薬）の使い方を前もって確認

6こころと相談を大切に

  • 気分の落ち込み・不安が続くときは、遠慮なく相談を
    → てんかんではよくあること。一人で抱えこまないで
  • 発作日誌をつける。妊娠・仕事・制度のことも主治医へ

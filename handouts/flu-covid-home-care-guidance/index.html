コロナと言われたら

発症した日を「0日目」として数えます。

インフルエンザや新型コロナウイルスの検査で陽性と言われた後、家でどう過ごせばよいかをまとめました。薬はいつまでに飲むか、学校や仕事はいつまで休むか、家族にうつさないためにいつ動くかを、順番に確認してください。

動画・くわしい解説はこちら

1薬は「早いほど効く」、でも全員に必要ではありません

  • インフルの薬は発症から48時間以内
    → 遅れると十分な効果は期待できません。ただし重症化しやすい方は、48時間を過ぎても使うことがあります
  • コロナの薬は発症から5日以内、または3日以内（薬による）
    → 薬の種類によって期限がちがいます。医師と相談してください
  • 「薬を飲めば重症化しない」わけではありません
    → 多くの方は薬がなくても自然に治ります。全員に必須の薬ではありません

2検査が陰性でも、「ちがう」とは言い切れません

  • 陽性が出たら、ほぼ本物と考えてよいです
    → まちがって陽性になることは、まれです
  • 陰性でも、インフルやコロナでないとは言い切れません
    → 検査で見つけられないことがあります。症状だけで見分けるのも難しいとされています

3いつまで休むか（学校・保育所・大人）

  • 学校（インフル）＝発症後5日 ＋ 解熱後2日（幼児は3日）
    → 熱が下がっただけでは足りません。両方満たすまで休みます
  • 学校（コロナ）＝発症後5日 ＋ 症状が軽くなって1日
    → どちらか一方だけでは、まだ足りません
  • 保育所（インフル）＝発症後5日 ＋ 解熱後3日
    → 保育所のめやすは学校とすこし違います
  • 大人（コロナ）＝発症した日を0日目として5日間 ＋ 5日目に症状が続くなら軽くなって24時間
    → 大人も「日数」と「症状」の両方です。そのあと10日目までは、まわりの人のためにマスクを。出勤できる日数は勤務先の規則によります
  • 治癒証明書・陰性証明書は不要です
    → 学校にも職場にも、あらためて提出を求める必要はないとされています

4家でうつさない工夫は「最初の1日半」が勝負

  • 熱が出てから、36時間以内に対策を始めてください
    → 早く始めるほど、家族にうつるのを防ぎやすいとされています
  • 手洗いと換気、部屋の湿度は50〜60%を目安に
    → 窓を2か所開ける、少しずつ開け続けるなどの工夫が効果的です
  • 手指の消毒はエタノール濃度80%前後のものを
    → 石けんでの手洗いも、あわせて続けてください

5家での過ごし方と、すぐ相談する目安

  • 水分は、飲みたいものでかまいません
    → お茶でもスープでも大丈夫です。無理に決まった飲み物にしなくてよいです
  • 解熱薬は「つらさを取る」ために使います
    → 熱を無理に下げきる必要はありません。しんどさが和らぐ量で使ってください

6子どもの異常行動は、薬のせいとは限りません

  • 発熱から2日間は、一人にしないでください
    → 薬を飲んでいなくても、飲んだ薬の種類に関わらず起こることがあります
  • 玄関や部屋の窓の施錠を。できれば1階で休ませてください
    → 転落などの事故を防ぐための対策です

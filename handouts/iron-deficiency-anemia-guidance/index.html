鉄が足りない貧血と
言われたら

ヘモグロビンが戻っても、まだ終わりではありません。

鉄が足りないことで起こる貧血（鉄欠乏性貧血）と言われたときに、鉄剤をどう飲むか、いつまで続けるか、食事で何ができるか、そして「なぜ鉄が足りなくなったのか」を調べる意味をまとめました。

動画・くわしい解説はこちら

1鉄剤の飲み方

  • 1日1回、おなかがすいているときに飲むのが基本
    → 食事と一緒だと吸収が落ちます。朝起きてすぐや、食事の間が向いています
  • 気持ちが悪くて飲めないときは、自分でやめる前に相談を
    → 量を減らす、飲む時間を変える（夕食後や寝る前）、種類を変える、1日おきにするなど、続けるための方法があります
  • 便が黒くなります。心配はいりません
    → 錠剤をつぶすと金属の味がします。尿の色が変わることもありますが、問題ありません

2ヘモグロビンが戻っても終わりません

  • ヘモグロビンは6〜8週で正常に戻ります
    → ただし、そこは治療の終わりではありません
  • 正常に戻ってから、さらに3か月ほど続けます
    → 体にたまる鉄（フェリチン）が回復するまで、時間がかかります
  • 自分の判断でやめると、また貧血に戻りやすくなります
    → やめる時期は、血液検査を見て決めます

3効いているかは1か月で確かめます

  • 飲みはじめて4週間ほどで、血液検査をします
    → 上がり方が思わしくないときは、原因を考え直します
  • 飲んでいるのに上がらないとき、考えること
    → 出血が続いている、胃薬（胃酸を抑える薬）を飲んでいる、吸収がうまくいかない、などがあります
  • 貧血が治ったあとも、半年ごとくらいに血液検査を
    → また鉄が足りなくなっていないか、早めに見つけるためです

4食事でできること・できないこと

  • 1日にとりたい鉄は、月経のある女性で10.0〜10.5mg、男性で7.0〜7.5mg
    → 年齢によって少し変わります。月経のある方は、必要量が大きく増えます
  • 食事だけでいまの貧血を治すことはできません
    → 治すのは鉄剤の役割です。食事は、くり返さないために役立ちます
  • サプリをたくさん飲んでも、貧血の予防にはなりません
    → 必要な量を大きく超えてとることは、治療目的以外では控えるようにとされています

5お茶とビタミンC、よくある誤解

  • 鉄剤は、お茶で飲んでもかまいません
    → お茶で飲んでもヘモグロビンの増え方は変わらないとされ、とくに禁じる必要はないという考えが定着しています
  • いっぽう「食事の鉄」は、お茶の影響を受けます
    → 食事とお茶を1時間ほど空けると、影響は小さくなります
  • 鉄剤にビタミンCを足す必要はありません
    → 大きな研究で、足しても効果は変わりませんでした。ただし「食事の鉄」は、ビタミンCと一緒だと吸収が上がります

6「なぜ鉄が足りないのか」を調べます

  • 鉄剤を出して終わりにはしません
    → 足りなくなった理由がわかると、くり返すのを防げます。検査を待つ間も、鉄剤は始めてかまいません
  • 月経のある方は、婦人科の相談をすることがあります
    → 経血の量が多い、子宮筋腫などが原因として多いためです
  • 男性・閉経後の方は、胃カメラ・大腸カメラをおすすめすることがあります
    → 胃や腸からの出血が原因のことが多いためです
🔍 ここが誤解されがち
貧血だから、鉄をたくさん飲みたい量を増やしても、吸収される量はそれに比例して増えません。少ない量でも同じようによくなることが示されています
ヘモグロビンが戻ったのでやめましたいちばん多い中断の理由です。そこからさらに数か月続けないと、また戻ってしまいます
レバーを毎日食べれば治りますか食事はくり返しの予防に役立ちますが、いまある貧血を治すのは鉄剤です
「いつまで飲めばいいですか」と聞かれたら、ヘモグロビンが正常に戻ってから、さらに3か月ほどが目安です。最終的には、体にたまる鉄（フェリチン）の値を見て決めます。
⚠️ すぐに相談してほしいとき
便に血が混じる鉄剤による黒い便とは別に、出血のサインのことがあります
動悸・息切れが強い階段や平らな道でも苦しいとき
めまいで立っていられないふらついて歩けないとき
鉄剤が続けられない吐き気などで飲めないときは、やめる前に連絡してください
妊娠中・授乳中の方は、産婦人科の指示に従ってください。必要な鉄の量や検査の進め方が、この資料とは変わります。
🍚 鉄をとりやすくする食べ方
肉・魚の鉄は吸収されやすい牛・豚・鶏、レバー、赤身の魚の鉄は、他の食品より2〜3倍よく吸収されます。ただし脂質も多いので、とりすぎには注意してください
海藻・野菜・大豆の鉄は吸収されにくいほうれん草、切り干し大根、大豆、ごまなど。量をとる工夫が必要です
ビタミンCと一緒にとると上がります食事とオレンジジュースなどを合わせる方法がすすめられています
牛乳・チーズは間食で食事と一緒だと鉄の吸収を下げるため、おやつの時間に回します
極端な食事制限は鉄不足のもとにダイエットで食べる量が減ると、鉄も足りなくなります
